# TD80 Voice Search

Нативное Android-приложение для голосового поиска на проекторе TD80 Pro (и подобных Droidlogic-устройствах без Android TV).

## Проблема

Проектор TD80 Pro работает на "голом" китайском Android — нет встроенного голосового поиска как в Android TV. Кнопка голосового поиска на пульте генерирует ASSIST key (keyCode 219), но система его не обрабатывает.

## Решение

Приложение перехватывает нажатие кнопки поиска на пульте, распознаёт голос, ищет по TMDB и показывает карточки с постерами. При выборе — запускает нужное медиа-приложение с поисковым запросом.

### Поддерживаемые приложения

- **NUM** (ru.yourok.num)
- **SmartTube** (org.smarttube.stable)
- **Lampa** (ru.yourok.lampa)
- **LazyMediaDeluxe** (com.laxymedia.deluxe)

### UX

1. Нажал кнопку поиска на пульте → открылся экран поиска
2. Сказал "аватар 2" → появились карточки с постерами из TMDB
3. Нажал на карточку → детали фильма + кнопки приложений (точный поиск)
4. Кнопки приложений внизу экрана → быстрый поиск по сыровому запросу
5. Нажал NUM → NUM открылся с поисковым запросом

## Стек

- **Kotlin** — основной язык
- **Android SDK** — minSdk 33 (Android 13), targetSdk 34
- **Leanback** — TV UI framework, тёмная тема
- **OkHttp + Moshi** — сеть и JSON
- **Coil** — загрузка постеров
- **SpeechRecognizer** — голосовой ввод (Speech Services by Google)
- **AccessibilityService** — перехват ASSIST key с пульта
- **TMDB API v3** — метаданные и постеры фильмов/сериалов

## Архитектура

Provider-based: `SearchProvider` интерфейс → `TmdbSearchProvider` (первый). Каждый провайдер — независимый модуль. Позже можно добавить реверс-инжиниринг API NUM/SmartTube как отдельные провайдеры — ничего не ломается.

Подробно: [specs/2026-04-11-voice-search-design.md](specs/2026-04-11-voice-search-design.md)

## Тестирование

Эмулятор не используется. Проектор — основное устройство тестирования через ADB.

Рабочий цикл: `код → gradlew assembleDebug → adb install -r → adb logcat | grep VoiceSearch`

Debug-сборка содержит кнопку "Симулировать голос" для тестирования без микрофона.
